# Anish Kumar - Professional Resume & Portfolio

An executive, print-optimized single-page A4 resume engineered specifically for web viewing and flawless **Browser Save as PDF** export.

## 🚀 Key Specifications

- **Single-Page A4 Precision**: Configured to exact ISO A4 standard (`210mm × 297mm`) with zero page-break overflow or trailing blank pages.
- **Dedicated Print Stylesheet (`@media print`)**:
  - High-contrast **black and dark ink text on crisp white background**.
  - Precise page margins: `@page { size: A4 portrait; margin: 12mm 14mm 10mm 14mm; }`.
  - Removes all interactive icons, arrows, and web navigation elements during print/PDF generation.
  - Hardened against browser clipping using CSS fragmentation (`break-inside: avoid; page-break-after: avoid;`).
- **Recruiter & ATS-Optimized Typography**:
  - Font: **Inter** (Google Fonts) with an 8px baseline grid and readable print point sizes (`9pt–20pt`).
  - Categorized, scannable technical skills (Languages, Web Tech, Tools, Core Competencies).
- **Enriched Profile Sections**:
  - **Professional Summary**: Direct, high-impact career summary.
  - **Work Experience**: Industry internship at Techsharthi Academy.
  - **Featured Projects**: Astrosharthi (AI Web Application), DevFolio Resume, and Polytechnic Academic Portal.
  - **Education**: Diploma in CSE at GP Gaya & 10th CBSE (84% Distinction) at Saraswati Vidya Mandir.
  - **Certifications & Honors**: Techsharthi Python credential and academic merit.

## 🖨️ How to Save as PDF

1. Open `index.html` in Google Chrome, Microsoft Edge, or any modern browser.
2. Press **`Ctrl + P`** (or **`Cmd + P`** on macOS).
3. In the Print dialog:
   - **Destination**: *Save as PDF*
   - **Paper size**: *A4*
   - **Margins**: *Default* (or *None* — both render an exact 1-page document)
   - **Options**: Uncheck *Headers and footers*
4. Click **Save**.
